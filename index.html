A State-Based Add-Wins CRDT for RDF Datastores

Jitse De Smet, Ruben Taelman

IDLab, Department of Electronics and Information Systems, Ghent University – imec, Ghent, Belgium

Problem

  • Multiple agents concurrently write to shared RDF knowledge graphs.
  • Decentralized ecosystems (Solid, IDSA, Gaia-X) — no central authority.
  • Offline editing → write conflicts on reconnect.
  • Existing approaches: dedicated servers (m-ld) or consistency boundary problems (binary blobs outside dataset).

Approach

  • State-based OR-Set CRDT over RDF 1.2 triple terms.
  • All bookkeeping in a single dataset — no external blobs or servers.
  • Add-wins: concurrent add + remove → triple survives.
  • Transparent: agents use standard SPARQL, unaware of CRDT merge.

State-Based OR-Set in RDF 1.2

  • Each triple carries unique add-tags (UUIDv4); removal moves tags to a tombstone set.
  • A blank node links triple term, add-tags, and tombstones via crdt:tags.
  • Triple is present ⟺ ≥1 add-tag not in tombstone set.
  • On merge: identifying nodes for the same triple are consolidated.

Web Synchronization

  • State-based merge aligns with REST semantics — exchange full state, not operations.
  • ETag + conditional PUT prevents mid-air collisions — no extra infrastructure.
  • Implements RDFjs Store interface → plugs into Comunica for SPARQL.
  • CRDT-aware and unaware clients coexist on the same data.

NTP Tombstone Optimization

  • Without GC, tombstones accumulate indefinitely.
  • NTP bounds: max 2000s drift between any two clients.
  • crdt:stamp-uuid tags enable time-based pruning.
  • Tag universally seen after d + 4000s → safe to prune.
  • Works in open ecosystems — no known replica set required.

Conclusion & Future Work

  • Add-wins set CRDT modelled entirely in RDF 1.2.
  • No consistency boundary — bookkeeping within the dataset.
  • Transparent conflict resolution for agents and SPARQL clients.
  • PoC: orset-rdf-store on npm.
  • Future work: constraint-aware merge — valid states can merge into constraint-violating states.
